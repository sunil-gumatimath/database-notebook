# Advanced Topics

Four subjects beyond the core querying chain — each in its own subfolder.

| Topic | Folder | Highlights |
| :--- | :--- | :--- |
| Indexes | [`indexes/`](indexes/) | `CREATE INDEX`, composite indexes, `SHOW INDEX`, `DROP INDEX` |
| Views | [`views/`](views/) | Virtual tables: `CREATE VIEW`, `OR REPLACE`, updatability |
| Sequences | [`sequences/`](sequences/) | Auto-incrementing values with dialect notes for Oracle, PostgreSQL, SQL Server, and MySQL |
| Transactions | [`transactions/`](transactions/) | ACID, `COMMIT`, `ROLLBACK`, `SAVEPOINT`, isolation levels |

## Suggested Order

1. [`indexes/`](indexes/) — shortest of the four; best appreciated once queries get slow.
2. [`views/`](views/) — practical immediately, builds directly on querying skills.
3. [`sequences/`](sequences/) — reference material for auto-incrementing keys.
4. [`transactions/`](transactions/) — conceptual groundwork for real applications.
